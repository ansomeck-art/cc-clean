# HTTPS 正文解密退役与只读观察（3.5.0 build 12）

2026-11-27，产品退役原软件内 HTTPS MITM / 上传筛选。当前应用不运行该代理，不检查上传正文，不提供准备、信任证书或经筛选启动 Claude 的入口。原 `start`、`trust`、`launch` 接口拒绝重新启用；`stop` 仅保留清理用途。Claude 可按正常方式打开。

本次不安装、移除或变更已有证书信任，不修改系统代理、VPN、路由、hosts、Claude 文件或启动参数。退役不能解释为旧 CA 已被删除或历史信任已撤销。升级需先正常退出旧 RegionGuard，再打开新版；旧运行实例不会自动热升级。若旧后台仍报告服务运行，页面会明确提示，不能谎称已停用。

## 当前保留的只读来源

- 文件：Sentry scope、应用配置和 Electron 偏好只分类允许的明确地区字段；离线队列、桌面/MCP 配置、Cookie 和安装标识只观察元数据；日志仅输出固定分类计数。完整八组清单见[进程保护说明](PROTECTION.md)。
- 连接来源：后台独立线程随后台监控持续读取，不依赖网页或全扫；监控 `traffic` 显示两组当前样本、最近样本增量与本次监控历史，扫描项 `claude_traffic_coverage` 保留一次性证据。PID/控制器关联未知不等于物理绕行，DIRECT 不等于内核路由选择；独立 curl、TUN / Global 或一个连接不能证明所有组件流量。
- 服务响应：扫描项 `service_response_diagnostics` 与日志来源的 `diagnostics` 将不同拒绝/故障原因分开，只作排查提示，不把任意 403 都解释为地区限制或封禁。
- 客户端版本：后台公网 Pulse 周期和全面扫描读取版本元数据，卡片仅读缓存，`client_version_review` 提供变化后的轻提醒；显式确认只更新自身基线，不影响保护。版本读取不在 100ms 保护路径，更新也不证明新版本已被完整验证。

| 固定响应分类 | 说明 |
| --- | --- |
| `region_denied` | 服务明确地区拒绝 |
| `permission_denied` | 服务权限拒绝 |
| `ip_restricted` | 明确 IP 限制 |
| `edge_challenge` | 边缘验证或挑战 |
| `account_banned` | 明确封禁码 |
| `network_timeout` | 网络超时 |
| `http_forbidden_unknown` | 403 原因未明 |
| `network_error` | 网络错误 |
| `http_error` | 其他 HTTP 错误 |

页面只使用固定中文标签和计数，不展示日志行、URL、Cookie、凭据、账号、MCP 名称、安装标识或文件路径。旧七类 `counters` 仍作为兼容提示；不能将它们混成同一服务拒绝原因。不同服务和不明确的原因分别保留，不能由中文语言判断国籍或实际所在地。

## 文件保护与网络保护分别判定

文件缺少 Sentry culture、locale、timezone 时为待观察；核验中、格式未知、读取失败或结果陈旧仅提示未核验，不凭这些未知状态强退。文件保护只对明确中国大陆字段触发：国家/地区明确 CN、大陆时区或 locale 中明确 CN 区域段。单独 `zh`、`zh-Hans`、中文话题、UTC+8 或英文设备名都不是该触发条件。

已经观察到的明确 CN 风险及固定来源保持锁存，直至守护线程处理；启动已有风险同样检查。已确认 CN 风险或连接路由绕行事件处理/解除后需要新的公网复核；普通未知或待观察恢复不因此触发强退。网络守护的独立严格策略继续生效，包括启动、唤醒、重大路由变化及公网验证过期。强退可能丢失未保存内容，软件不会自动重开 Claude。

## 连续观察的三种路由证据

入站 TUN/本地代理、控制器代理/DIRECT、内核逐真实目的 IP 路由分别统计，不能互相代替。只有已确认的真实公网目的有效物理路由绕过 TUN，才会形成待处理 `connection_route_bypass` 事件并交给既有身份保护；局域网、本地/FakeIP、普通未知和 DIRECT 本身不构成它，且它不等于中国地区已确认。

内核目的路由是未限定接口的最长前缀配置证据，不能证明每个 socket 的实际接口绑定或数据包已经发送；不会把 SDK 未明确说明的字段猜作真实出接口。

原生观察默认约 500ms，限定 PID 的 lsof 回退有效周期至少 2000ms；界面约每 1 秒显示缓存，以实际周期为准。未知、停止、API 断开/超时或陈旧撤销当前关联；曾观察待处理事件单列，历史风险计数不会冒充当前证明。历史随本次监控累计，暂停保留、下次启动重置；最近样本增量不是两个网页刷新之间的全部新增，新连接首次样本仅建基线，首样本已有明确绕行仍记录处理；统计与去重有界，各类历史可能重叠，不相加推算总数。

## 不能据此承诺的内容

当前不检查 HTTPS 上传正文，不能阻止内存 EventLogging、离线队列正文或未知来源上传。短连接、已结束连接、未连接 UDP 和采样间隙即使提高频率也可能读不到。文件观察无法拦住首次写入，也不能保证发现风险早于上传。100ms 是本地接口和受检文件的配置周期，非响应硬上限；公网复核仍为 15/30/60 秒。只读证据不等于全部流量覆盖、零直连、零泄漏或服务端地区/账号决定。

历史筛选计数只说明旧运行中记录过相应次数，不代表当前仍在筛选，不证明来源 PID 或全部端点覆盖。兼容返回的零计数也不能作为安全证据。旧 `telemetry_runtime.py`、worker、证书和 policy 源码可留作隔离回归参考；当前 macOS 应用不导入或打包这些启用模块及策略资源，文档不再提供启动步骤。
