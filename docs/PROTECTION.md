# macOS 3.5.0 build 12 进程保护与只读多源观察

2026-11-26，用户明确要求将告警型守护升级为毫秒级本地检测，并能在异常时终止 Claude 进程。该次授权允许对确认的 Claude Desktop 主程序及 Helper 强制退出。3.4.0 已退役原 HTTPS 正文解密与上传筛选，改用只读文件、连接来源及服务响应证据，详见[退役与只读观察说明](TELEMETRY_FILTER.md)。进程保护仍不等于流量拦截。

3.5.0 build 12（2026-11-27）新增后台持续连接观察，保留八组文件来源与仅明确中国大陆字段触发策略。缺文化字段、核验中、格式未知、读取失败或陈旧仅作待观察提示；网络守护继续独立采用严格策略。不同服务响应原因分开，客户端更新轻提醒。软件不更改、清理或重写客户端文件，不检查 HTTPS 上传正文。

## 如何使用

启动 `RegionGuard.app`，或执行 `./start.sh --tray`，在菜单栏或真实浏览器监测台确认以下两项同时开启：

1. 后台持续监控。
2. 异常时自动强制退出 Claude。

macOS 的自动退出偏好默认开启；旧偏好文件没有此字段时同样使用开启默认值。若暂时只需要观察，请先暂停监控或关闭自动退出开关。关闭“系统弹窗通知”只会静音，不会停止进程保护。

“本地检测间隔”可选 50、100、250、500 毫秒，默认 100 毫秒。“公网复核频率”保持 15、30、60 秒，默认 30 秒。退出 RegionGuard 后不再保护；程序不会自动写入登录启动项。

升级时先从菜单正常退出旧 RegionGuard，再打开新构建的应用。现有旧实例不会因磁盘上的应用文件更新而自动获得 3.5.0 的后台连接观察、文件触发策略和解密退役状态；旧后台缺少 `sources` 时，页面明确显示来源尚未验证。

## 何时会强制退出

网络守护保持严格策略：已经确认的网络危险和网络安全未确认阶段均可能触发进程处理。以下网络条件不因文件待观察策略改变：

- 启动时尚未取得有效的公网安全结果。
- 系统唤醒，或重要 TUN 路由发生变化，尚未完成新的出口复核。
- 有效公网 IPv4 路由缺失、绕过 TUN、TUN 接口离线，或可用物理 IPv6 有绕过风险。
- 公网探测失败、国家不匹配、进入受限地区或出口 IP 跳变。
- 公网结果过期，或本地安全状态无法读取。
- 已验证 Claude 的真实公网目的 IP 存在绕过 TUN 的有效物理路由；控制器 DIRECT、局域网、本地/FakeIP 地址或未知不等于该正向事件。
文件保护另行判定：只有受检 Sentry、应用配置或 Electron 偏好中的白名单地区字段出现明确中国大陆国家/地区标记、locale 中明确 CN 区域段或大陆时区时触发；启动时已存在的危险字段同样检查。缺少 culture、locale、timezone、核验中、格式未知、读取失败或结果陈旧均不凭这些未知状态强退，页面以黄色待观察提示，也不据此宣称地区安全。

保护线程独立于公网请求、日志写入和界面通知，文件 I/O 也由独立线程承担。已被观察到的明确中国地区风险连同固定来源类型保留至守护线程处理，短暂写入后立即恢复不会自动清掉尚未处理的风险；文件事件合并或未被读到的瞬时内容不在此保证内。风险持续期间，再次启动被确认的 Claude Desktop 仍可能被下一轮检查退出。已经观察到的明确 CN 风险或连接路由绕行事件处理/解除后要求新的公网复核；普通未知或核验中恢复不会因此触发强退。风险解除后**不会自动重启 Claude**，请按正常方式手动打开。

未发现受检文件单独显示“待观察”，不因文件缺失本身强退，也不以此声称文件安全。后端网络条件可能已满足，页面仍保留文件范围未验证的提示。

强退使用 `SIGKILL`，可能丢失未保存内容或中断正在执行的任务。若系统拒绝终止，程序会报告失败，不会静默声称已关闭，也不会尝试 sudo、申请更高权限或更改系统设置。

## 目标范围与误杀防护

目标仅限 `/Applications/Claude.app` 或 `~/Applications/Claude.app` 中、Bundle ID 和主可执行文件符合预期的应用：Claude Desktop 主程序以及精确路径匹配的 Claude Helper。Helper 组另含这两处应用根目录内精确的 `Contents/Frameworks/Electron Framework.framework/Versions/A/Helpers/chrome_crashpad_handler`；其他浏览器的同名 Crashpad 均拒绝纳入。

信号发送前会重新确认单个 PID、所属 UID、启动时间和程序路径，拒绝复用 PID、身份变化或无权确认的目标。不使用 `killall Claude`、`pkill -f claude` 或向整个进程组广播信号。

这些检查不是密码学身份认证；复核和发送信号并非一个原子操作，仍有很小的 PID 复用竞态窗口。

当前不会终止 Safari、Terminal、其他应用，也不会把外部 Claude Code CLI、全局 node/ssh 或所有 Claude 的子孙进程一概纳入范围。应用安装在其他目录时，不应假定它会被当前白名单覆盖。

## 检测方式与速度含义

本地快速路径使用进程内 `getifaddrs` 和只读 `sysctl NET_RT_DUMP2`，检查接口及相关公网有效路由。PF_ROUTE socket 只接收变化通知，不发送路由修改消息；周期采样保留为兜底。正常主机路由缓存变化不应被当作 TUN 断开。

文件线程按以下固定清单观察。界面始终列出八组，缺失、未知、暂停及旧后台不省略为“全部通过”。仅使用固定中文来源名、国家/地区、区域语言、时区等字段类型和数值证据，不显示实际字段值、账号信息、服务器名称、日志行或文件路径。

| 来源 | 观察方式 | 能提供的证据与边界 |
| --- | --- | --- |
| Sentry 文化与地区 | 地区字段检查 | 检查 `scope_v3.json` 的文化与明确地区元数据；文化字段暂缺本身为待观察，已出现的明确 CN 字段仍检查。 |
| Sentry 离线队列 | 仅元数据 | 观察文件数量、大小、变化；不读取队列正文，地区未核验。 |
| 应用配置 | 地区字段检查 | 只分类允许的明确地区字段；普通配置文本或英文设备名不作为地区安全证据。 |
| Electron 偏好 | 地区字段检查 | 检查允许的国家/地区、区域语言、时区字段；正常只表示受检字段未见指定风险。 |
| 桌面 / MCP 配置 | 仅元数据 | 观察文件变化；不读取配置正文、MCP 名称或凭据，地区未核验。 |
| Cookie 存储 | 仅元数据 | 观察文件及伴随文件元数据；不读取 Cookie 值，写入成功不证明地区安全。 |
| 安装与设备标识 | 仅元数据 | 观察标识文件变化；不读取标识值，新标识不证明地区安全。 |
| Claude 日志码 | 固定分类码 | 服务拒绝/故障九类分别统计，保留旧七类码兼容；普通错误仅作提示，不触发文件强退。 |

文件数、字节和截断限制通过“有界观察”标明，不表示已检查全部历史。日志计数仅针对本次观察线程生命周期内实际检查的部分：首次每文件最多读取尾部 512 KiB，之后从已核验位置每轮最多检查 512 KiB；不展示或保存日志行原文。零错误、88 条记录、稳定计数、Cookie 写入或安装标识变化均不能推导为地区安全。

使用只读文件事件观察并保留周期检查，没有向文件写入过滤规则。普通元数据变化和普通日志错误码不作为中国大陆字段风险；仅明确 CN 字段触发文件强退。文化字段暂缺、核验中、解析失败和陈旧均只提示未核验，不强退，不把它们伪装为已确认安全。网络未知仍按独立严格策略处理。

离线队列正文、内存 EventLogging、其他未列来源和未经过筛选服务的上传请求不在地区字段核验范围内。文件正常不代表所有遥测或服务端账号地区判定正常，也不能拦住首次写入或保证早于上传。HTTPS 正文解密已退役，不再提供接入或证书操作；未检查上传正文，已有证书信任不由软件安装或移除。

100ms 是本地网络与受检文件的配置检查周期，事件可提前唤起复核，并非响应硬上限。操作系统调度、内核采样、文件写入与读取、进程枚举与复核、信号执行均会增加延迟；已经发送或由内核排队的数据包无法由此撤回。TUN 接口仍在、但隧道上游已故障或出口国家已变化时，发现问题可能需要等待公网请求完成。

公网出口/IP/国家验证仍受网络延迟和接口可用性影响，不能改成可靠的毫秒级 GeoIP 判定。本功能不拦截流量，不能承诺“零泄漏”“首次异常请求前一定拦住”或账号安全结果。

## 后台持续连接观察

连接观察是独立线程，随后台监控启动/停止，不依赖网页打开或全面扫描，也不因关闭自动强退开关就停止只读观察。原生接口默认约 500ms；不可用时回退到仅查询已验证 PID 的 lsof，有效周期至少 2000ms。界面沿用约 1 秒监控轮询读取缓存，不新增观察定时器或制造探测连接。实际周期以界面为准，500ms 不是响应硬上限。

只报告固定 Claude 主程序 / Claude Helper 两组，私有的 PID、地址、端口、连接标识、节点和路径仅作内存关联，不输出原值。表格明确区分：

- 当前样本：进程/socket 数、已匹配与未匹配数，以及入站 TUN/本地代理/未知、控制器代理/DIRECT/未知、内核目的路由 TUN/物理绕行/阻断/本地/未知三种维度。
- 最近样本增量：仅后端最近一轮的新连接/绕行数，不是两次网页刷新之间的总数；新连接首次样本只建基线，首样本已有明确绕行仍记录并交保护处理。
- 本次监控累计：历史已关联、新增、DIRECT、未知和物理绕行计数；暂停保留，下次启动或显式重置清零。各类可能重叠，去重和数量有界，不相加推算总连接数，也不等同完整请求历史。

DIRECT 是控制器选择，不等同物理直连或中国出口。目的 IP 的有效物理公网绕行才可进入 `connection_route_bypass` 待处理锁存事件，由既有进程身份复核和保护处理；它不是中国地区已确认，也不表示强退已经完成。即使后续样本未知或陈旧，先前已观察待处理事件仍可单独保留；停止清除此事件。普通关联未知不触发强退。

当前状态未知、停止、API 断联/超时或样本超过 `stale_after_ms=max(1500, 3×实际周期+500)` 时，界面撤销当前证明，累计仅保留为历史；恢复后需要新鲜样本才能再显示当前关联。现有网页轮询也会撤销已经过期的旧显示，不以卡住的请求保留旧证明。短连接、已结束连接、未连接 UDP、读取间隙和白名单外进程/CLI 仍可能未被观察；不检查上传正文，TUN / Global 不证明全流量覆盖或零直连。

## 状态与记录

逐目的地址的内核路由核验采用未限定接口的最长前缀路由表。它证明存在相应路由配置，不能穷尽核验每个 socket 的接口绑定，也不证明数据包实际已经从该接口发出；保护按这一明确路由风险处理。

网页与原生菜单栏显示自动退出开关、本地周期、保护状态、最近采样耗时和强退指令统计。保护告警会覆盖历史正常 Pulse 的绿色显示；暂停监控或关闭保护后，不再执行终止动作。

网页无法读取后台状态或请求超时时，会撤销原先的正常提示并显示保护状态未知。线程停止显示自动退出不可用；身份/权限检查失败会提示手动退出 Claude。关闭保护请求失败时，控件恢复到最近确认值，并明确说明原保护可能仍运行；只有后台确认关闭后才应视为已关闭。

文件观察汇总与八组来源分别显示待观察、核验中、受检字段未见指定风险、仅观察元数据、日志提示、明确 CN 风险、未知、未发现文件和暂停状态。仅元数据来源明确写“地区未核验”；完整的八组运行状态也只表示有限观察，界面不使用全覆盖安全绿色。暂停不会继续拿上次结果证明当前安全。观察年龄、检查耗时、检查次数、变化次数、文件数和固定后端类型只提供有限运行证据；同一文件反复变化会增加检查次数，不代表发现多个文件。

- `GET /api/monitor/status` 的 `protection` 提供进程保护状态；独立的 `traffic` 提供连接观察 `running/state/interval_ms/stale_after_ms/samples/event_seq`、样本年龄/耗时、固定后端、两组 `evidence`、`history` 和待处理 `action_reason_codes`，全流量覆盖标志固定 false。
- `protection.telemetry` 保留 `state`、固定 `reason_codes` / `field_types`、`last_check_age_ms`、`last_scan_ms`、`backend`、有限 `coverage`、`files_checked` 和 `event_seq`；增加固定八组 `sources` 数组及锁存的 `risk_source_ids`。`telemetry_backend_available` 单独报告文件观察后端可用性。
- 每组仅提供固定 `id`、`state`、`mode`、原因码/字段类型、`change_count`、`file_count`、`total_bytes`、`files_checked`、结果年龄、旧七类数值 `counters`、可选九类 `diagnostics` 和 `limited`。汇总与来源都允许 `observed`；它表示待观察或该模式的有限证据，不代表文化字段齐备或地区已核验。
- `GET/POST /api/prefs` 增加 `protection_enabled` 与 `local_interval_ms`，沿用本地 Host/Origin/POST 安全校验。
- `~/Library/Application Support/RegionGuard/protection-events.jsonl` 保存最近 100 条自身保护事件，目录 0700、文件 0600，始终位于应用包外。记录风险类型和统计，不输出节点地址、凭据、账号 UUID、硬件公钥或完整目标路径。

扫描项 `service_response_diagnostics`、`claude_traffic_coverage` 和 `client_version_review` 分别提供服务响应原因、只读连接来源和版本变化轻提醒。地区拒绝、权限拒绝、IP 限制、边缘验证、封禁、超时、原因未明的 403、网络错误及其他 HTTP 错误分开；日志码不是所在地或账号资格的最终判定。仅启用 TUN / Global 或观察到部分连接不证明所有组件必无直连，版本变化也不单独强退。

版本元数据由后台公网 Pulse 周期或全面扫描读取，避开 100ms 保护路径；版本卡片只读缓存，用户可点击“已复核版本变化”仅确认当前显示版本并更新自身基线，失败保留提醒，旧版本确认不能清除较新提醒，后台不会自动确认或改变保护条件。

成功次数表示成功发出强退信号；信号调用返回的瞬间，目标进程不一定已经完全消失。终止请求、权限拒绝和身份拒绝应分别查看，不能仅凭累计数字假定当前所有相关活动都已停止。

## 验证范围

标准回归通过模拟命令、信号、时钟和临时数据验证误杀边界、过期/乱序结果、唤醒隔离、暂停/关闭、异常与恢复。真实 AppKit 冒烟测试验证状态和菜单勾选。

`tests/smoke_fast_protection.py` 读取真实内核并对返回的安全状态做逻辑故障注入；生产信号路径只接收该测试自己创建的可丢弃子进程。它不修改路由、不关闭 VPN、不终止真实 Claude。机器可读结果为 `build/fast-protection-smoke.json`，包含本地采样、故障到信号、观察到子进程退出的不同延迟。

Shell 与打包冒烟使用独立的 RegionGuard 测试状态目录运行，不借用正在运行的用户旧实例，也不覆盖用户偏好。默认生产数据目录仍是 `~/Library/Application Support/RegionGuard/`；测试目录覆盖仅用于受约束的开发隔离。

3.1 历史构建冒烟（100ms 配置、100 次内核采样、12 个自有子进程）记录：内核采样中位数 1.225ms、故障到信号 P95 100.126ms、观察到退出 P95 125.616ms。结果随机器负载和重新运行变化，只说明该样例的已测表现，不构成当前文件观察耗时、实时性或零泄漏承诺。历史 121 项 Python、5 组 CJS 回归与镜像证据，以及后续版本的实际验收范围见 [验收记录](ACCEPTANCE.md)。
